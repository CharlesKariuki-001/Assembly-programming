# Assembly Programming

This repository documents my journey learning Assembly Programming and low level computer systems.

I am studying Assembly to strengthen my understanding of how computers work at the CPU and memory level, with a focus on cybersecurity, reverse engineering, malware analysis, and security engineering.

## Why I Am Learning Assembly

High level languages such as Python and C hide many hardware details.

Assembly exposes them directly.

By learning Assembly, I am developing an understanding of:

* CPU registers
* Memory
* Binary and hexadecimal
* Machine instructions
* The stack
* Program execution
* Function calls
* Compiled binaries
* Low level security vulnerabilities

These concepts are important for understanding how software actually works underneath the code.

## Security Focus

Assembly is especially useful in cybersecurity because security professionals often need to understand programs without having their original source code.

The knowledge from this repository will contribute to my understanding of:

* Reverse engineering
* Malware analysis
* Vulnerability research
* Binary analysis
* Memory corruption
* Exploit mitigation
* Low level defensive security

## Goal

The goal is not simply to learn Assembly syntax.

The goal is to understand what happens between software and the hardware running it, and eventually use that knowledge to build stronger cybersecurity systems.
