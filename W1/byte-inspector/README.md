# Byte Inspector

A small Python cybersecurity learning tool built during Week 1 of my Assembly Programming studies.

## What It Does

Byte Inspector can:

* Convert decimal numbers to binary
* Convert decimal numbers to hexadecimal
* Inspect text character by character
* Display character byte values
* Display hexadecimal values
* Display binary values
* Identify printable ASCII characters

## Example

For the character:

```text
A
```

The program shows:

```text
Decimal: 65
Hex:     0x41
Binary:  01000001
```

This demonstrates how a character can be represented as a byte and viewed in different number systems.

## Why It Matters for Cybersecurity

Binary and hexadecimal are commonly encountered when working with:

* Memory dumps
* Disassembled programs
* Binary files
* Network data
* Malware analysis
* Digital forensics

This project is a small practical exercise for developing that foundation.
